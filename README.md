# 🎙️ Telegram Voice TTS Bot (Piper TTS Custom Voice)

Este projeto consiste em um Bot do Telegram capaz de **coletar amostras de voz** do usuário, exportar o dataset e, posteriormente, utilizar um **modelo de Inteligência Artificial de síntese de voz (TTS)** treinado com a voz customizada para responder mensagens de texto com áudios clonados.

O motor de síntese de voz utilizado é o [Piper TTS](https://github.com/rhasspy/piper), rodando em container Docker otimizado para plataformas como Render, Railway ou VPS[cite: 3, 4].
